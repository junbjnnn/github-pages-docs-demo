# Trang Markdown trong Demo2

Trang này nằm ở `docs/demo2/markdown-page.md`. Không cần khai báo ở đâu cả:
script build quét cây `docs/` và tự thêm mục **Demo2** vào sidebar.

!!! tip "Thêm trang mới"
    Tạo file `.md` hoặc `.html` trong bất kỳ thư mục con nào của `docs/`, push lên `main`
    là sidebar tự cập nhật.
